# 预测记录规范（PREDICTION SCHEMA）

每条预测必须包含以下字段，缺一不可。这是公开承诺，不是草稿。

## 字段

| 字段 | 说明 | 必填 |
|---|---|---|
| 预测内容 | 一句话、可证伪。不允许模糊到任何结果都能圆回去 | ✅ |
| 置信度 | 0.0–1.0，发布时定死，结算后不得回改 | ✅ |
| 时间窗 | 起止日期，到期即结算 | ✅ |
| 结算判据 | 提前写死什么算 HIT、什么算 MISS | ✅ |
| 入链 hash | 发布前 continuity_core 固化的 hash | ✅ |
| 状态 | PENDING / HIT / MISS / ABSTAIN | ✅ |
| 发布日 / 结算日 | 日期 | ✅ |

## 不可违反的规则

1. **MISS 永久保留**：不删、不改、不辩护。
2. **发布后预测内容不可改**：hash 在链上，改了能查出来。
3. **ABSTAIN 是合法结局**：信息不足或超时，诚实写 ABSTAIN，不计入 HIT/MISS 的胜负，但单独统计 abstain 率。
4. **净胜率账本**：每条结算后更新 `ledger.md`，累计 HIT/MISS/ABSTAIN 和净胜率（对比朴素热度基线）。

## 朴素热度基线

净胜率的对照基线。对每个预测主题，取"当前最热的那一个"作为朴素预测，如果时晴的预测不显著优于它，账本会诚实显示。
